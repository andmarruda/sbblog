The writing console for blogs that live anywhere.

SBBlog keeps writing and editing in one place and sends every change as an event. Each blog's site keeps its own data on Cloudflare D1, R2 or a local SQLite, so no central server carries the weight of every blog.

Features

Everything a newsroom needs, nothing a reader has to wait for.

One console for every blog you run, built on Laravel, React and PostgreSQL.

An editorial workflow

A rich editor, revision history with diffs, suggestions with inline comments, review, scheduling and translations.

Many blogs, one workspace

Workspaces hold several blogs, with invitations and seven built-in roles, from owner to viewer.

Every change is an event

An ordered log per blog with JSON Schemas, snapshots for new sites, and a viewer to inspect every payload.

Sites own their data

Register each site with its store, D1, R2 or SQLite. It pulls or receives events and never calls the console to read.

Themes and integrations

Versioned themes with their own settings, and analytics or ads scripts that load only after the reader consents.

Security built in

Passkeys, two-factor authentication, trusted devices, a strict content security policy and a full audit log.

Apps and API

An OAuth install flow for apps, personal access tokens and a content API to create drafts and suggestions.

Comments with moderation

Sites send reader comments to the console, which applies each blog's policy, rate limits and spam checks.

Bilingual from day one

The console speaks Portuguese and English, and every blog can publish in several languages.

How it works

Write in one place. Serve from anywhere.

Write and publish

Your team writes, reviews and schedules in the console. Publishing records an event in the same transaction as the content.

Events reach your sites

Each site pulls new events or receives them by signed webhook, applies them in order and resumes where it stopped.

Readers hit the edge

Pages are served from the site's own store, on Cloudflare or your server. The console never sits in the reader's path.
